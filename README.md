# 🚕 Uber Ride Performance Analytics Dashboard
📌 Project Overview

This project is an interactive Uber Ride Performance Analytics Dashboard developed using Microsoft Power BI.

The dashboard provides a comprehensive analysis of Uber ride performance, including booking trends, vehicle performance, revenue analysis, customer behavior, ride completion status, cancellations, and payment methods.

The project is designed to transform raw Uber ride data into meaningful business insights through interactive visualizations, KPIs, DAX calculations, and data storytelling.

🎯 Project Objectives

The main objectives of this project are to:

Analyze overall Uber ride performance.
Track completed and lost bookings.
Monitor total revenue and distance travelled.
Analyze monthly booking and revenue trends.
Compare the performance of different vehicle types.
Understand customer behavior and customer categories.
Analyze revenue by payment method.
Identify top customers based on revenue.
Analyze ride cancellations and incomplete rides.
