# 🚕 Uber Ride Performance Analytics Dashboard

## 📌 Project Overview

This project is an interactive **Uber Ride Performance Analytics Dashboard** developed using **Microsoft Power BI**.

The dashboard provides a comprehensive analysis of Uber ride performance, including booking trends, vehicle performance, revenue analysis, customer behavior, ride completion status, cancellations, and payment methods.

The project transforms raw Uber ride data into meaningful business insights through interactive visualizations, KPIs, DAX calculations, and data storytelling.

---

## 🎯 Project Objectives

The main objectives of this project are to:

- Analyze overall Uber ride performance.
- Track completed and lost bookings.
- Monitor total revenue and distance travelled.
- Analyze monthly booking and revenue trends.
- Compare the performance of different vehicle types.
- Understand customer behavior and customer categories.
- Analyze revenue by payment method.
- Identify top customers based on revenue.
- Analyze ride cancellations and incomplete rides.

---

# 📊 Dashboard Pages

The dashboard currently consists of **five interactive pages**.

## 🏠 1. Home Page

The Home page acts as the landing page for the dashboard.

It provides navigation to the following sections:

- Overview
- Vehicle
- Revenue
- Customers

This allows users to easily explore different areas of the Uber Ride Performance Analytics Dashboard.

## 📈 2. Overview Dashboard

The Overview page provides a high-level summary of Uber ride performance.

### Key KPIs

- **Completed Rides:** 149K
- **Lost Bookings:** 57K
- **Total Revenue:** 52M
- **Total Distance:** 2.51M
- **Average Ride Distance:** 24.64

### Visualizations

- Completed Bookings Trend by Month
- Revenue Trend
- Revenue by Vehicle Type
- Customer Rating
- Driver Rating
- Ride Completion Status

### Ride Status Analysis

The dashboard categorizes rides into:

- Completed Rides
- Cancelled Rides
- Incomplete Rides

## 🚗 3. Vehicle Analysis

### Vehicle Types Analyzed

- Uber XL
